# YouTube Downloader Guide (`yt-dlp`)

A practical guide, command-line cheat sheet, and documentation for downloading YouTube videos and audio using [`yt-dlp`](https://github.com/yt-dlp/yt-dlp).

---

## 📌 Prerequisites

Before running the commands, ensure you have `yt-dlp` and `ffmpeg` installed on your system.

- **`yt-dlp`**: The core command-line media downloader.
- **`ffmpeg`**: Required for post-processing (merging video + audio formats, extracting audio, etc.).
